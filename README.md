# MythicMixtapeStudios Portfolio

Next.js App Router site for Mythic Mixtape Studios™ — Videos, Games, Playlists, Library (Publishing), and Shop (Shopify when ready).

**Live:** https://mythic-mixtape-studios.vercel.app

## Local

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Content

Edit `data/content.ts` for studio copy, YouTube links, games, library categories, and `studio.shopUrl` (Shopify storefront URL).
